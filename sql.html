WHAT IS SQL?

SQL:

SQL is a standard query language for sorting, manipulating and retrieving the data in the database.

What Can SQL do?:
  • SQL can execute queries against a database
  • SQL can retrieve data from a database
  • SQL can insert records in a database
  • SQL can update records in a database
  • SQL can delete records from a database
  • SQL can create new databases
  • SQL can create new tables in a database
  • SQL can create stored procedures in a database
  • SQL can create views in a database
  • SQL can set permissions on tables, procedures, and views
RDBMS:

RDBMS stands for Relational Database Management System.

RDBMS is the basis for SQL, and for all modern database systems such as MS SQL Server, IBM DB2, Oracle, MySQL, and Microsoft Access.

The data in RDBMS is stored in database objects called tables. A table is a collection of related data entries and it consists of columns and rows.

CREATING A DATABASE:

Syntax: CREATE DATABASE DATABASE_NAME

SQL COMMANDS:
1. Data Query Language (DQL)

Used specifically for retrieving data from the database.

SELECT: Fetches records from one or more tables.

2. Data Manipulation Language (DML)

Used to add, modify, or delete data within existing table structures.

INSERT: Adds new rows to a table.

UPDATE: Modifies existing records.

DELETE: Removes specific rows based on a condition.

3. Data Definition Language (DDL)

Used to define and manage the structure (schema) of a database.

CREATE: Used to build new database objects.

ALTER: Modifies the structure of an existing object, such as adding, deleting, or renaming columns in a table.

DROP: Permanently deletes an entire object (like a table) and all its data from the database.

TRUNCATE: Removes all records from a table while keeping the table structure intact.

RENAME: Changes the name of an existing database object.

COMMENT: Adds or modifies descriptive comments about an object in the database's data dictionary.

4. Data Control Language (DCL)

Used to manage user access, permissions, and security for a database.

GRANT: Used to give specific access privileges or permissions (such as SELECT, INSERT, UPDATE, or DELETE) to a user or role on database objects like tables or views.

REVOKE: Used to take away or withdraw previously granted permissions from a user or role.

5. Transaction Control Language (TCL)

Used to manage transactions in a database. A transaction is a sequence of one or more SQL operations treated as a single unit of work.

COMMIT: Saves all changes made during the current transaction permanently. After commit, changes cannot be rolled back.

ROLLBACK: Undoes all changes made in the current transaction. Returns the database to the last committed state.

SAVEPOINT: Creates a point within a transaction to which you can later roll back. Useful for partial rollbacks.
