WHAT IS POWER BI?

POWER BI:

It is a Data Visualization and Business Intelligence tool which helps to convert data from different data sources into interactive dashboards and BI reports.

It provides visualization with self service business intelligence where end users can create reports and dashboards by themselves, without depending on IT staff or database administrators.

What is Business Intelligence:

It is the collection of methods and tools that analyze raw data.

It refers to strategies and methods used by companies for performing data analysis of any business information.

BI works on ETL process i.e. extraction, transformation and loading of data in a database, which includes data mining, online analytical processing and business reporting.

Organizations use BI to improve their performance and operations effectively.

Power BI tools:

1. Power BI Desktop

Main development tool for building reports and dashboards

Connects to Excel, SQL, APIs, cloud data, etc.

Used For:

  • data cleaning
  • modelling
  • DAX calculations
  • visual creation
2. Power BI Service

Web version (online portal)

Publish reports from Desktop

Share dashboards with teams

Schedule refresh

Create apps and workspaces

3. Power BI Mobile

View dashboards on phone/tablet

Real-time alerts

Mobile-friendly monitoring

4. Power BI Report Builder

Used for paginated reports (print-ready reports)

Best for invoices, tables, operational reports

5. Power Query

Data cleaning tool

Remove duplicates

Merge tables

Transform columns

Uses M language

6. DAX (Data Analysis Expressions)

Formula language in Power BI

Used for:

  1. measures
  2. calculated columns
  3. KPIs
7. Power Bi Apps

These are mobile applications that are available for windows, iOS and android devices.

You can share dashboards and reports with other users, which they can access on their smartphone over the internet.

8. Power Bi Gateway

It is installed by admin, acts as a bridge between the power bi and on-premises data sources such as excel, DirectQuery, PowerApps, Azure analysis, etc,.

A Gateway is used to connect on-premises data sources (local servers, SQL databases, Excel files, SAP, etc.) to Power BI cloud services.

Types of Gateway:

On-premises Data Gateway (Standard Mode)

Used by multiple users

Supports:

  1. Power BI
  2. Microsoft Power Apps
  3. Microsoft Power Automate
  4. Azure Analysis Services

Best for enterprise environments

On-premises Data Gateway (Personal Mode)

Supports:

  1. Used by single user
  2. Only supports Power BI refresh
  3. Simple for personal dashboards
