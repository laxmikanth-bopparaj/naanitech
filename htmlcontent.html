WHAT IS HTML?

HTML:
  • HTML is a Hyper Text Markup Language.
  • The purpose of html is to create web pages(static).
  • It is not a case sensitive language.
  • It is an interpreter language.
  • It communicates with the browser.
Types of Tags:
  1. Paired Tags.
  2. Unpaired Tags.
PAIRED TAGS:

Tags that are having both open and close tags with the content in between are called paired tags.

Syntax: <tag name>content</tag name>

Example: <p>Describes Paragraph</p>

UNPAIRED TAGS:

Tags that are having only open tag but not close tag are called unpaired tags.

Syntax: <tag name>

Example: <hr> Describes Horizontal line.

Example: <br> Describes Single line break.

Essential HTML Tags:
  • <html>

    • The root element that encloses the entire HTML document.

  • <head>

    • Contains meta-information about the page, such as its title, character set, and links to stylesheets, which is not visible to the user.

  • <title>

    • Sets the title of the web page, which appears in the browser's title bar or tab.

  • <body>

    • Contains all the visible content of the web page, including text, images, and links.

  • <h1> to <h6>

    • Describes Headings, h1 is the largest size and h6 is the smallest size.

  • <p>

    • Defines paragraph of text.

  • <b>

    • Defines the thickness (bold) of a text.

  • <a>

    • Anchor tag used for page navigation by creating a hyperlink.

  • <ul> and <ol>

    • Creates unordered lists (bullet points) and ordered lists (numbers).

  • <li>

    • Defines list items within <ul> and <ol>.

  • <div>

    • Used for making separate divisions

  • <i>

    • Defines italic font style.

  • <strong>

    • Defines important text. The content inside is typically displayed in bold.

  • <span>

    • Used to mark a part of text by adding inline css.

  • <form>

    • Creates a form for user inputs.

  • <bdo>

    • tag is used to override the current text direction. It stands for Bi-Directional Override.

  • <button>

    • Defines a clickable button.

  • <blackquote>

    • Specifies a section that is quoted from another source.

  • <br>

    • Defines single line breaks.

  • <caption>

    • Defines the table caption. tag must be inserted immediately after the <table> tag.

  • <col>

    • Specifies column properties for each column within a <colgroup> element.

  • <colgroup>

    • specifies a group of one or more columns in a table for formatting.
